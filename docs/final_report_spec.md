# Спецификация итогового аналитического доклада

## Название

“Глобальная карта образовательной миграции в Россию: новые рынки, прогноз до 2050 года и управленческая модель привлечения иностранных студентов”.

## Формат

Доклад должен быть воспроизводимым артефактом, собираемым из тех же данных, что и GitHub Pages. Допустимые форматы: Markdown + HTML/PDF export, либо DOCX/PDF при отдельном скрипте сборки. Внутри GitHub Pages должна быть краткая executive-страница с ключевыми таблицами и интерактивными ссылками на источники.

## Обязательная структура

1. Управленческое резюме.
2. Концептуальная модель международной образовательной миграции в Россию.
3. База OD-потоков 2010–2025: источники, покрытие, ограничения.
4. Демографические рынки молодёжи до 2050 года.
5. Гравитационная модель притока иностранных студентов в Россию.
6. Индекс дружелюбности и образовательной восприимчивости к России.
7. Вакансии и компетенции: спрос на международно-экономические, управленческие, цифровые и аналитические навыки.
8. Прогноз потенциальной образовательной миграции в Россию по странам, макрорегионам и направлениям.
9. Разрыв фактического и потенциального притока, рейтинг нереализованного потенциала.
10. Новые образовательные рынки для российских вузов и МГИМО.
11. Матрица “страна — образовательная программа — язык обучения — инструмент привлечения — ожидаемый эффект”.
12. Приложения: словарь данных, source registry, методика нормализации, модельные карты, ограничения.

## Правила ссылок

Каждая числовая таблица должна иметь машинно-считываемые ссылки на source passport. В тексте допускается округление, но таблица-приложение должна позволять воспроизвести исходное значение.

## Запрещено

Нельзя включать в доклад строки, которых нет в curated/model outputs. Нельзя описывать модельные прогнозы как фактические потоки. Нельзя замещать отсутствующую статистику “оценкой LLM”.
