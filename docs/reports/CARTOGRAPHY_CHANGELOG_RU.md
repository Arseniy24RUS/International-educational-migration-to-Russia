# Изменения версии 5.3: картограммы и флаги

В печатный доклад добавлены 6 автоматически формируемых картограмм, отдельная методическая страница, локальные SVG-флаги в страновых профилях и рейтингах, пересчёт нумерации страниц и строка нового раздела в содержании.

Все картографические ресурсы автономны и пригодны для GitHub Pages. География: `data/world_admin_boundaries_ru_claimed_update_2026.geojson`. Проекция: Equal Earth. Классификация: семь квантильных классов.
