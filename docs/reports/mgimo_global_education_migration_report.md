# Аналитический отчёт MGIMO Platform 2.0

## Управленческий вывод

Публичный слой собран из текущего release mart и сохраняет разделение между наблюдаемыми фактами, официальными демографическими проекциями, модельными оценками и управленческими индексами. Наблюдаемые образовательные строки берутся из UNESCO UIS OPRI; последний содержательный год для рейтингов России — 2023. Нулевая выгрузка UIS за более поздний год сохранена как аудиторский след и не используется как лидерский рейтинг.

PPML-модель `ppml_russia_inbound_structural_allocation_v3` имеет статус `validated_structural_model_not_short_term_point_forecast`. Её роль — структурное распределение и анализ недопредставленности, а не точечный краткосрочный прогноз численности студентов. Для прогноза до 2050 года публикуется структурная ёмкость распределения и отдельный инерционно-демографический benchmark.

Трудовой слой «Работа в России» остаётся fail-closed: частичный record-level снимок содержит 29 046 обезличенных уникальных вакансий, 3 001 классифицированную строку и 4 126 строк доказательств классификации; 26 из 27 тематических запросов завершены без truncation. Поэтому уникальная генеральная совокупность вакансий не сертифицирована, а зависимые population-level показатели заблокированы.

## Интерпретация таблицы

`UIS actual stock` — наблюдаемая официальная численность за последний содержательный год. `Structural capacity 2026`, `Continuity baseline` и `Structural gap` — модельные или расчётные значения. Положительный разрыв означает недопредставленность относительно демографически-инерционного benchmark внутри структурного распределения; это не дополнительный национальный набор и не causal effect кампании.

## Источники и покрытие

Паспорта источников опубликованы в `docs/data/platform2/source_manifest_platform2.json` и в dashboard source drawer. Главные источники: UNESCO UIS OPRI, UN WPP 2024, World Bank API, UN Digital Library voting data, Pew Global Attitudes, MGIMO partner references, модельные артефакты PPML/friendliness/country-program и официальный API «Работа в России».

## Ограничения релиза

1. Полная тематическая record-level выборка Trudvsem не сертифицирована из-за повторяющегося HTTP 500 официального API на запросе `государственное управление` после 10 000 загруженных строк.
2. Search-result totals Trudvsem пересекаются и не являются числом уникальных вакансий.
3. Legacy source manifest содержит источники, для которых explicit redistribution/license note не был зафиксирован в исходном поставленном манифесте; release остаётся blocked до отдельной source/license clearance.
4. Страново-программная матрица — управленческий индекс приоритета, а не прогноз студентов, вакансий или causal effect.
